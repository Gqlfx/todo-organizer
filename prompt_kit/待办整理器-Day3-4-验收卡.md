> 前置：`npm run dev`，页面停在「队列」Tab。

## 一、两条必过

| # | 动作 | 预期 | 通过 |
|---|---|---|---|
| 1 | 输入框一次粘 24 行（每行一句话），回车 | 顶部「今天 24 件 · 已排 2 件」，出现「今天到此为止」，线下每条标「明天」，底部「还有 22 件没排上」 | ☐ |
| 2 | 用下面的片段造一个 15 分钟碎片，再建一条 10 分钟任务 | 任务卡落在碎片里（时间在固定事件之间），碎片剩余 5 分钟不再显示空档线 | ☐ |

## 二、造数据（还没有录入 UI 的部分）

浏览器控制台（仅 `npm run dev` 时可用）：

```js
// ① 造两个固定事件，把今天夹成「已经很紧」的样子：
//    第一个从现在之前开始（否则开头那一大段整块会先把短任务吃掉，轮不到碎片）
const pad = (n) => String(n).padStart(2, '0')
const iso = (d) => `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}T${pad(d.getHours())}:${pad(d.getMinutes())}`
const now = new Date()
const a0 = new Date(now.getTime() - 30 * 60000)
const a1 = new Date(now.getTime() + 120 * 60000)
const b0 = new Date(now.getTime() + 155 * 60000)
const b1 = new Date(now); b1.setHours(23, 0, 0, 0)

await __todo.addTask({ title: '电路实验', is_fixed: true, start_at: iso(a0), end_at: iso(a1) })
await __todo.addTask({ title: '班会', is_fixed: true, start_at: iso(b0), end_at: iso(b1) })

// ② 再建一条 10 分钟任务：a1+10 到 b0-10 之间正好 15 分钟碎片，它必须落在这里
await __todo.addTask({ title: '取快递', est_min: 10 })
```
