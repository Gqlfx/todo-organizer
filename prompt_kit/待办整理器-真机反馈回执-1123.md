## 一、软任务的最早开始时间（`not_before`）

### 为什么需要

现在只有两档：

```
is_fixed = true   →  start_at 是硬开始，占死时间
is_fixed = false  →  没有任何时间锚点，first-fit 从 max(now, work_start) 开始
```

缺中间那一档：**「我打算八点做，但它可以被挤」**。

`queue.ts` 里软任务装填从 `windowStart` 起算，所以 19:57 交的任务就排在 19:57——用户说的时间被丢掉。

### 判定规则由谁定：正则，不是 AI

**不看「有没有说时间」，看「有没有说具体钟点」。**

| 输入 | 钟点 | is_fixed | 结果 |
|---|---|---|---|
| 明天下午三点开会 | 15:00 | true | `start_at = 15:00` |
| 晚上八点开始刷题 | 20:00 | false | `not_before = 20:00` |
| 今天写完实验报告 | 无 | false | 无锚点，从 now 排 |
| 买猫粮 | 无 | false | 无锚点，从 now 排 |

只接受**明确钟点**（「八点」「20:00」「下午三点」），不接受模糊时段（「下午」「晚上」「今天」）。

这条规则用字符串匹配就能落，**不交给模型判断**——模型会飘，今天解析成锚点、明天不解析。

### 实现要点

1. `Task.not_before: string | null`，Dexie v5，只加字段不迁移数据
2. parse 契约加第 9 条，明确与 `start_at` 互斥：
   - `is_fixed = true` → 只填 `start_at`
   - `is_fixed = false` 且有明确钟点 → 只填 `not_before`
3. 装填时软任务起点取 `max(空档起点, 已用到, not_before)`
4. **不做回填**：19:00–20:00 空着是允许的，你说八点就是八点

### 验收

交「今晚八点开始刷题半小时」→ 卡片显示 20:00–20:30，不是创建时刻。

### 状态：已实现（2026-11-23）

- `src/lib/notBefore.ts`（新）：正则提取，30 条用例全过。含误伤保护——
  「快一点 / 早一点 / 晚一点再说」都返回 null，「一点」必须带量词或完整时段词才算钟点。
- `src/db/db.ts`：Dexie v5 加 `not_before: string | null`（存 `"HH:mm"`，只表示当天时刻），
  只加字段、不改索引、不迁移数据。
- `src/db/tasks.ts`：建卡时就算锚点（不等模型）；解析回 `is_fixed = true` 时把锚点清掉，
  避免同一条任务有两个开始时刻。
- `src/lib/queue.ts`：装填起点取 `max(空档起点, not_before)`；**锚点跳过的那段切回空档池**，
  留给没有锚点的任务——否则一条「晚上八点」会把整条时间轴推到八点，后面的任务跟着遭殃。
  「不做回填」约束的是这一条任务本身。
- **prompt 一行没改**：模型仍然只输出 `is_fixed` / `start_at`，没有 `not_before` 这个字段。

三句一起交的实测（`now` 固定 11-23 15:00）：

| 输入 | 落点 |
|---|---|
| 晚上八点开始刷题半小时 | 20:00–20:30 |
| 今天写完实验报告 | 15:30–16:30（前面 30 分钟被另一条占了） |
| 买猫粮 | 15:00–15:30 |

30 项断言全过。

## 二、「明天」标签改成「今天装不下」

`plan_date` 仍是 null、`bucket` 仍是 `today`，所以全部页仍归「今天」。队列却标「明天」——同一件事两个说法。

改法：队列 overflow 卡片与全部页 today 分组统一用「今天装不下」。不承诺时间，只说事实。

验收：两处说的是同一个词。

## 三、拖拽（前两条验完再做）

项目里没有 dnd-kit，没有 `DndContext`，`src/` 里没有拖拽代码。用户摸到的震动是 Android WebView 的长按默认行为。

实现约束：

- 只改顺序，不改时间：拖完重新装填，时间自动算
- 固定行不可拖
- 长按 300ms 进入拖动，上下移动，松手落位
- 拖完 `slot_source='user'` + `is_locked=true`，卡片变实线
- 已锁定卡片有「解锁」入口

验收：拖完刷新位置不变；点「重排」也不动它。
